# Portal Lembaga Cerdas Al-Qur'an (LCA)

Situs statis Portal LCA (Yayasan Al-Kalam). Satu berkas `index.html` ditambah folder `media/`.

- Dideploy di Railway (project `tafaqur-app`, layanan `portal-lca`). Railway otomatis membangun ulang setiap ada commit ke `main`.
- Seri **Materi Al-Qur'an** baru ditambahkan setiap Senin oleh tugas terjadwal Claude (section `p-materi-N` di `index.html`).
- Kalender Hijriah memakai tabel KHGT (1447–1455 H) di dalam `index.html`.
